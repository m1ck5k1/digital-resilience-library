# MED — Index

> Category: **MED** · Medical & First Aid · Reference + Template.

Medical knowledge is the highest-stakes content in this library — it can help or it can harm.
So MED here follows a strict rule (from `FRAMEWORK.md`): **public MED = T1-institutional
sources only** (WHO, CDC, Red Cross) **+ a "not medical advice" disclosure.** Nothing
unverified gets in.

## Reference docs (public)
- [`emergency-response-cpr-stroke.md`](./emergency-response-cpr-stroke.md) — when to call
  9-1-1, the check-the-scene sequence, **adult CPR** (100–120/min, 30:2, ≥2 in), **Hands-Only
  CPR**, and **stroke recognition (Act F.A.S.T.)**. Grounded in Red Cross + CDC, with WHO
  context. **Not medical advice.**

## Household template (`library/templates/`)
- [`MED-household-health-plan.md`](../templates/MED-household-health-plan.md) — fill in YOUR
  members/conditions, emergency contacts & providers, current medications, first-aid kit
  contents, and who-does-what. **Fill locally; your answers never enter this repo.** Review
  with a clinician/pharmacist.

## Place in the build order
MED is the medical layer of the survival stack. It sits alongside the others (WATER, FOOD,
ENERGY, SAN, NAV, SHELTER) as the first-response knowledge a household needs on top of them.
It is seeded **Reference-first** to make clear that the value is verifiable, first-response
knowledge — not treatment, which always belongs with professionals.

## Status note on this seed
The MED reference is staged for **human re-approval** before push (per the MED gate). It
covers recognition + basic adult CPR + stroke F.A.S.T.. Planned future additions (severe
bleeding / Stop the Bleed, choking, anaphylaxis) are **not yet authored** and will only be
added from verified T1 sources — never guesswork.
