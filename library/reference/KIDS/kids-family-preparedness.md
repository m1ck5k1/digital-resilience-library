# KIDS — Family & Kids Emergency Preparedness

> **Public framework only.** Per CATEGORIES.md / FRAMEWORK.md §3.2: KIDS = Template (household plan — identifying data = user data, never in repo) + Reference (this universal framework). Any identifying detail (child's name, school, phone, meeting-point address, medical/allergy details, caregiver assignments, specific evacuation routes) belongs **only** in `library/templates/KIDS-family-emergency-plan.md`, never here.

> **Not a substitute for professional family/child-care counseling or school-specific emergency plans.** Confirm any procedural steps against current school / county / Red Cross guidance.

## What this reference covers (universal, public, non-identifying)
- **Contact-tree structure** (who notifies whom; chain order; out-of-area contact role) — the *pattern*, not names/numbers.
- **Meeting-point framework** (primary / secondary / out-of-area criteria; how to pick them) — criteria only (walkable, public, outside hazard zone, known to family). No actual addresses.
- **School-protocol awareness** (how schools handle reunification; what parents confirm with the school) — generic guidance only. Specific school names, phone extensions, and reunification-point details → template.
- **Age-appropriate explanation framework** (what to explain at different ages; comfort-item categories; practice schedule) — framework only.
- **Caregiver / guardian assignment pattern** (primary / backup / out-of-area; who confirms) — pattern, not names.

## What stays out of this file (template-only / user-data; §2.2 / §4.2 / §6)
- Child / parent / guardian names.
- School names, addresses, specific reunification-point details.
- Actual meeting-point addresses, family home address, evacuation-route specifics.
- Phone numbers (cell / work / school office / out-of-area contact).
- Medical / allergy details, medication names/doses; special-needs descriptions.
- Caregiver-specific assignments ("Aunt M at 123 Elm").
These go **only** in the blank `library/templates/KIDS-family-emergency-plan.md` (template = public, filled = user private data, stays with user / not in repo).
