# LEGAL — Essential Documents & Forms

> Category: **LEGAL** · Part: **Reference** · Mapping (FRAMEWORK.md §3): Template = blank scaffold (`library/templates/LEGAL-important-papers-inventory.md`); Reference = this public-form guide.
> **Public tier only:** only forms/guidance that are legal to redistribute and verifiable from official sources. Any identifying entry (names, SSN, property descriptions, account numbers, attorney details) is **user data — lives only in the template / filled `household.json`, never in this repo**.

## What belongs here (public, verifiable, redistributable)
- **Court / government forms** (official blank forms): probate, small-estate, guardianship, restraining/order — linked by jurisdiction (federal / state / county / tribal). Always point to the official site; never reproduce copyrighted form instructions beyond brief description.
- **Estate-planning framework** (not a completed will): what a will / durable POA / health-directive / living-will covers; where to find verified blanks per state (state bar / court site / NCSC). No pre-filled examples with personal identifiers.
- **Document inventory checklist — framework** (categories): birth / marriage / adoption; property deed / lease; insurance policies; tax returns; military / benefits records. The *categories*, not your values. Actual inventory → `library/templates/LEGAL-important-papers-inventory.md`.

## What stays out of reference (template-only / user-data)
- Completed will / trust / POA text with names, property descriptions, beneficiary lists.
- Social Security / account numbers, specific institution names, asset values.
- Attorney / notary / witness names; family contact details; property street addresses.
- Any identifying family or household detail.

These go **only** in the blank `library/templates/LEGAL-important-papers-inventory.md`. Per framework §2.2 / §4.2 / §6: template = blank; any field filled by user = their data (lives with them, never in repo).

## Source / licensing hygiene (§5 / §6 — load-bearing for public tier)
- Source registry entry must be added to `sources-registry.md` per form source (official site URL, jurisdiction, access date, license = US-public-domain / official-publication).
- License recorded per reference file: US-government public domain for government forms; CC0 / public-domain guidance for framework synthesis.
- No paywalled, Terms-of-Service-violating, or unverified source. Any source that cannot be verified live is moved to the hold-list (same mechanism as FOOD/sources-and-safe-hold.md), not fabricated.
