# LEARN — Index

> Category: **LEARN** · Skills & Trades · Reference.

Skills are what turn stored knowledge into action. LEARN holds the **do-it** basics a household
or individual can practise — universal, non-identifying, and grounded in public-domain/
institutional sources.

## Reference docs (public)
- [`firecraft.md`](./firecraft.md) — the fire triangle, site prep, tinder/kindling/fuel, the four
  fire lays, and many lighting methods. Grounded in the US Army FM 21-76.
- [`knots-ropework.md`](./knots-ropework.md) — bowline, sheet bend, clove hitch, two half-hitches,
  taut-line hitch, the **critical "never use a binding knot as a bend"** warning, and natural
  cordage/lashing. Knots from Wikipedia (CC BY-SA); cordage from FM 21-76.
- [`hand-tool-safety.md`](./hand-tool-safety.md) — the universal hand- and power-tool safety
  baseline (what misuse does, sparks, PPE, power-tool precautions). Grounded in OSHA 3080.
- [`improvised-field-tools.md`](./improvised-field-tools.md) — making a blade from stone/bone/wood/
  metal, spears & arrow points, clubs/bola/throwing-stick, and natural cordage. Grounded in FM 21-76.

## Why LEARN completes the set
LEARN is the last of the core survival categories (after WATER, FOOD, ENERGY, SAN, NAV, SHELTER,
MED, SEC, LEGAL, COMMS, KIDS). It captures the *skills* layer — the practised knowledge that
underpins all the reference how-tos. It is Reference-only (skills are universal, not household
data).

## Status note
LEARN is seeded with four sourced docs. As with every category, additions only enter from
**verified** public-domain/institutional sources — never invented technique. Where the only
fetchable source is lower-tier (e.g. Wikipedia for knot-tying steps, since no public-domain FM
covers named knots), that tier is flagged in the doc rather than hidden.
