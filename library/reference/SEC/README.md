# SEC — Index

> Category: **SEC** · Security & Safety · Reference + Template.

Security splits cleanly along the DRL's public/private line:

- **Public** — general *awareness* knowledge (hardening basics, protective design principles,
  home-inventory concept). Universal, safe to share.
- **Private (with you)** — *your* layout, codes, routes, and vulnerabilities. These never enter
  this repo.
